## Ví dụ cách sử dụng cuối cùng

Dưới đây là ví dụ về cách mong muốn sử dụng khi hoàn thành:

```python
# Đoạn code mẫu minh họa cách sử dụng
from module.xyz import SomeClass

# Khởi tạo
instance = SomeClass(param1, param2)

# Sử dụng
result = instance.some_method(input_data)

# Xử lý kết quả
processed_result = do_something_with(result)
```

Hoặc mô tả các kịch bản sử dụng bằng văn bản nếu không cần code.

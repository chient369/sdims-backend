## 2. Yêu cầu Phi chức năng (Non-Functional Requirements)

(Giữ nguyên như bản trước, có thể bổ sung yêu cầu về hiệu năng/độ chính xác của AI Agent nếu cần thiết kế chi tiết hơn)

| ID    | Loại Yêu cầu          | Yêu cầu Cụ thể                                                                                                         | Ghi chú / Ưu tiên |
| :---- | :-------------------- | :--------------------------------------------------------------------------------------------------------------------- | :---------------- |
| NF-1  | **Hiệu năng**         | Thời gian phản hồi cho các thao tác xem/tìm kiếm UI thông thường < 2 giây.                                              | Cao               |
| NF-1a |                       | Thời gian phản hồi của AI Agent cho các truy vấn thông thường < 3-5 giây (tùy độ phức tạp LLM).                          | Cao               |
| NF-2  |                       | Thời gian tải Dashboard tổng hợp < 5 giây với dữ liệu của 1 năm.                                                         | Cao               |
| NF-3  |                       | Thời gian tạo báo cáo chi tiết (VD: margin nhân sự cả bộ phận) < 10 giây.                                                 | Trung bình        |
| NF-4  |                       | Hệ thống có khả năng chịu tải đồng thời từ [Số lượng người dùng ước tính, VD: 50-100] người dùng trong giờ cao điểm.        | Trung bình        |
| NF-5  | **Bảo mật**           | Dữ liệu nhạy cảm (lương, chi phí, margin) phải được mã hóa khi lưu trữ (at rest) và truyền (in transit).                 | Rất cao           |
| NF-6  |                       | Phân quyền truy cập chặt chẽ dựa trên vai trò, đảm bảo người dùng (và AI Agent thay mặt người dùng) chỉ thấy dữ liệu được phép. | Rất cao           |
| NF-7  |                       | Xác thực người dùng an toàn (VD: mật khẩu mạnh, có thể tích hợp SSO nếu cần).                                             | Cao               |
| NF-8  |                       | Phòng chống các lỗ hổng bảo mật web phổ biến (OWASP Top 10).                                                              | Cao               |
| NF-8a |                       | Đảm bảo AI Agent không bị lợi dụng để truy cập dữ liệu trái phép (Prompt Injection, Data Leakage...).                     | Rất cao           |
| NF-9  | **Tính khả dụng**    | Hệ thống phải hoạt động ổn định, uptime tối thiểu 99.5% trong giờ làm việc.                                               | Cao               |
| NF-10 | **Tính dễ sử dụng** | Giao diện Web UI trực quan, nhất quán. Giao diện Chatbot tự nhiên, dễ hiểu.                                                | Cao               |
| NF-10a| **Độ chính xác (AI)** | AI Agent hiểu đúng ý định người dùng và trả về thông tin chính xác cho các truy vấn phổ biến > 90%.                       | Cao               |
| NF-11 |                       | Có hướng dẫn sử dụng cơ bản/tooltip cho UI và ví dụ cho Chatbot.                                                          | Trung bình        |
| NF-12 | **Khả năng bảo trì**  | Code base rõ ràng, tuân thủ standards, có comment. Kiến trúc AI Agent module hóa, dễ cập nhật/thay thế model.             | Cao               |
| NF-13 |                       | Dễ dàng cấu hình tham số hệ thống (ngưỡng, danh mục, prompt...).                                                         | Cao               |
| NF-14 |                       | Có hệ thống logging chi tiết (cả backend và AI Agent interactions) để gỡ lỗi và theo dõi.                                  | Cao               |
| NF-15 | **Khả năng mở rộng** | Kiến trúc cho phép dễ dàng bổ sung module/chức năng mới (cả backend và khả năng AI).                                      | Cao               |
| NF-16 |                       | Khả năng mở rộng CSDL, tài nguyên máy chủ, và tài nguyên AI (nếu self-host LLM/VectorDB) khi tải tăng.                  | Trung bình        |
| NF-17 | **Tích hợp**         | Tích hợp thành công và ổn định với Hubspot API.                                                                           | Rất cao           |
| NF-18 |                       | Có cơ chế (API/Import file/UI) cập nhật dữ liệu từ Kế toán hiệu quả.                                                    | Cao               |
| NF-19 | **Khả năng phục hồi** | Có cơ chế sao lưu (backup) dữ liệu (cả CSDL chính và VectorDB nếu có) và kế hoạch khôi phục.                            | Cao               |
